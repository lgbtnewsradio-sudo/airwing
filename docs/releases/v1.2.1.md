# AirWing 1.2.1

AirWing has been submitted to the Microsoft Store. Availability is pending
Microsoft review. Get the packaged app through the
[Microsoft Store listing](https://apps.microsoft.com/detail/9N3FMGF9168) when available.
Installer, portable and Store submission packages are not distributed through
this GitHub release. This release provides corresponding GPL source only.

## Changes

- Experimental AirPlay system audio using encrypted stereo 44.1 kHz ALAC.
- Audio follows the existing Include audio setting. AirPlay mirroring now supports
  volume and mute controls, with an initial stream volume of -12 dB.
- Short audio playback timing, bounded buffering and packet retransmission.
  Unsupported audio setup leaves video mirroring running.
- A 375-pixel-wide window, about one-third narrower, opening near the right edge
  of the display containing the pointer, within the usable desktop area.
- Store-first distribution: public packaged-app download attachments are retired.

132 local tests pass. Compact interface layout and package integrity were checked.
Physical Apple TV audio playback and synchronization still need validation.
Local tests are not Microsoft Store certification.
